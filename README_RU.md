# TG YouTube VPN — облачная сборка APK

## Что это
Исходный проект Android на Kotlin с WireGuard tunnel backend и GitHub Actions workflow для сборки APK в облаке.

## Функции
- Настоящий WireGuard userspace tunnel через библиотеку WireGuard Android.
- Split tunneling через IncludedApplications: Telegram (`org.telegram.messenger`) и YouTube (`com.google.android.youtube`).
- Редактируемый HTTPS API URL; загрузка конфигурации с `GET /config`.
- Ручная вставка WireGuard client `.conf`.
- Системное разрешение Android VPN.

## Сборка с телефона через GitHub
1. Создай аккаунт на https://github.com/ (если ещё нет).
2. Создай новый пустой репозиторий, например `tg-youtube-vpn`.
3. Загрузи содержимое архива в корень репозитория. Важно: загрузи и скрытую папку `.github/workflows/build-apk.yml`.
4. Открой вкладку Actions в репозитории.
5. Выбери `Build TG YouTube VPN APK` → `Run workflow`.
6. Дождись зелёной галочки у запуска, открой запуск и скачай `TG-YouTube-VPN-debug` в Artifacts.
7. Распакуй скачанный ZIP и установи APK. Android может попросить разрешить установку из этого источника.

## Требуется сервер
Сам APK не создаёт VPN-сервер. Нужен работающий WireGuard server и выданный им клиентский `.conf`. До получения конфигурации VPN-подключение не заработает.
Конфигурация должна содержать корректные `[Interface]` и `[Peer]`, ключи, Address, Endpoint и AllowedIPs.
API (если используешь) должен отдавать конфиг как обычный текст по HTTPS по пути `/config`. Не публикуй этот endpoint без авторизации: в клиентском конфиге находится приватный ключ. Для личного использования безопаснее пока вставить конфиг вручную.

## Ограничения этой первой сборки
- Проверка/сборка выполняется GitHub Actions; я не могу гарантировать успешную компиляцию до запуска workflow в твоём GitHub.
- Package IDs рассчитаны на официальные Telegram и YouTube. Клоны и альтернативные клиенты не включены.
- Нет автопереподключения, статистики трафика, смены локаций, импорта файлов и API-аутентификации.
- На некоторых Android-устройствах может понадобиться разрешить работу приложения в фоне.
- Не включай Always-on VPN/Lockdown до проверки соединения.
- Никогда не отправляй PrivateKey в чат, публичный репозиторий или открытый API.
